# โครงสร้าง Frontend

หน้าต่าง ๆ อยู่ใน `features/<หมวด>/pages` และเรียกข้อมูลผ่าน `useProjects()`
จาก `project/project-provider.tsx`

- `dashboard/`: ภาพรวมและเมนู
- `project/`: รายการงาน รายละเอียด ใบเสนอราคา วัสดุ ทีม และขั้นตอนงาน
- `employee/`: ทีมงานและงานที่มอบหมาย
- `appointment/`: นัดหมาย
- `payment/`: สรุปการชำระเงิน
- `shared/`: ส่วนแสดงผลร่วมกัน

ข้อมูลมาจาก API ผ่านโฟลเดอร์ `service/` ที่รากโปรเจกต์
แต่ละตารางมีฟังก์ชันเรียก API ของตัวเอง เช่น `getProject()` และ `updateProject()`
`service/workspace.ts` รวมข้อมูลแต่ละตารางเป็นโครงการที่หน้าจอใช้
provider เก็บข้อมูลที่โหลดไว้ใน React state ระหว่างเปิดหน้า และโหลดใหม่หลังบันทึก

หัวหน้าสร้างโครงการจากปุ่ม "สร้างโครงการ" ในหน้ารายการงาน
ฟอร์มอยู่ใน `project/components/create-project-form.tsx`
เลือกลูกค้าเดิมหรือเพิ่มลูกค้าใหม่ แล้วสร้างงานสถานะ pending ก่อนประเมินราคา

ตั้งค่าฐานข้อมูลตาม `schema/schema.sql` เดิม
รายละเอียดและตัวอย่างเรียกฟังก์ชันอยู่ใน [คู่มือ service](../service/README.md)

สถานะงานกับเงินแยกกัน งานปิดได้เมื่อ accepted และรับเงินครบ
รายการวัสดุเก็บใน job_material และราคาประเมินเก็บใน project
หลักฐานชำระเงินยังใช้ข้อความ/เลขอ้างอิง

หน้าบิลใช้รายการวัสดุและราคาปัจจุบันของโครงการ และต้องเข้าสู่ระบบ
ฟอร์มรอผลบันทึกจาก API และแสดงข้อผิดพลาดเมื่อบันทึกไม่สำเร็จ
